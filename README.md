# A.T International – Website

Single-page agency site (Srinagar, Kashmir), built on the Oitech "App Landing 3" layout with A.T International branding.

- `index.php` / `index.html` – the page (identical; use either)
- `contact.php` – enquiry form endpoint (sends mail to info@atinternational.online)
- `css/brand.css` – brand overrides (indigo palette, Outfit + DM Sans)

Upload the contents to your web root (PHP required for the contact form).
